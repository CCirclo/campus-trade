# 管理员操作说明（奖励机制 · 原石兑换 · 担保交易 · 校园认证）

本文面向管理员，说明虚拟货币奖励机制、在线币种支付、校园邮箱认证与白名单，以及每一步在管理后台的简单操作方式。

---

## 一、虚拟货币与奖励机制

平台有两种虚拟货币：

| 币种 | 说明 |
| --- | --- |
| 原石（lungmen） | 通用货币，发布/购买商品可获得，可兑换「自营」发布的商品 |
| 创世结晶（originium） | 稀有货币，用于抽奖与限定兑换 |

### 1. 注册奖励

新用户注册成功后，系统会自动发放一定数量的原石 / 创世结晶。

- **默认**：原石 100、创世结晶 1。
- 可开关、可调整数量、可选择是否只发给校园认证用户。

**操作步骤**：

1. 登录管理后台（`/admin`）。
2. 点击顶部导航的 **「奖励设置」**。
3. 在 **「注册奖励」** 区域：
   - `启用注册奖励` —— 勾选后新用户注册自动发奖，取消则不发。
   - `仅校园认证用户` —— 勾选后只有 `@ruc.edu.cn` 邮箱注册的用户才发奖。
   - `原石数量` / `创世结晶数量` —— 填写希望赠送的数量（0 表示不送该币种）。
4. 点击 **「保存设置」**，立即生效。

### 2. 自营账号与原石兑换

商品发布/编辑时，默认以「人民币」计价。只有被管理员标记为 **「自营」** 的账号，才可以发布用 **「原石」** 兑换的商品；普通账号只能发布人民币商品（仅提供交易信息，不做线上支付）。

**操作步骤**：

1. 进入管理后台 **「用户」**。
2. 找到目标用户，点击右侧 **编辑**（铅笔图标）。
3. 勾选 **「自营账号」**，保存。该用户发布商品时即可选择「原石」计价。
4. 取消勾选后，该用户只能发布人民币商品。

### 3. 发布与购买奖励

每发布一件商品，或每完成一件商品的原石购买（确认收货后），系统都会自动奖励 **原石**。

- **默认**：发布 +100 原石、购买 +100 原石。

**操作步骤**：进入 **「奖励设置」** → **「发布与购买奖励」** 区域，调整 `发布奖励（原石）` / `购买奖励（原石）`，保存即生效。

### 4. 手动发放奖励

除了自动奖励，管理员也可以随时给指定用户发币。

**操作步骤**：

1. 进入 **「奖励设置」** 页，找到 **「手动发放奖励」**。
2. 填写：用户邮箱、币种、数量（正整数，最多 1000000）、发放原因。
3. 点击 **「确认发放」**。发放会写入该用户的余额与流水，可在 **「查询用户钱包」** 中核对。

> 也可在服务器上使用命令行发放：
> `npm run grant -- <邮箱> <币种> <数量> <原因> --yes`
> 查询某用户余额与流水：`npm run grant -- --list <邮箱>`

### 5. 查询用户钱包

1. 在 **「查询用户钱包」** 区域输入用户邮箱，点击 **「查询」**。
2. 可看到该用户的原石 / 创世结晶余额，以及最近 50 条流水（含发放、购买、退款、售出）。

## 二、校园邮箱认证与白名单

### 认证是否强制？

- **浏览、搜索** 不需要认证，任何注册用户都可以。
- **发布商品、评论、收藏、发消息、在线购买** 需要「校园认证」。

### 什么是校园认证？

用户满足以下任一条件即视为「校园认证」：

1. 使用 `@ruc.edu.cn` 邮箱注册并通过验证；**或**
2. 被管理员 **手动认证**（即白名单机制）。

### 有没有白名单机制？

**有**。管理后台的 **「管理员手动认证」** 就是白名单：可以对任意邮箱（例如校内其他邮箱、特殊账号）手动开通校园权限，不受 `@ruc.edu.cn` 限制。

> 说明：目前没有「可配置的邮箱域名白名单列表」功能，系统只内置识别 `@ruc.edu.cn`；其他邮箱如需要校园权限，请通过手动认证逐个开通。

**操作步骤**：

1. 进入管理后台 **「用户」**。
2. 找到目标用户，点击该行右侧的 **编辑**（铅笔图标）。
3. 在弹窗中勾选 **「管理员手动认证」**，点击保存。
4. 该用户即可发布商品、评论、收藏、发消息（可在用户列表中看到认证状态变为「手动认证」）。取消勾选即可撤销。

## 三、在线币种支付（担保交易）

对于以「原石」计价的商品（仅自营账号可发布），买家可以直接用原石在线支付。采用 **担保交易** 模式：

1. **买家付款**：买家点击商品详情页的「立即购买」，系统立即从买家钱包扣除货款，商品状态变为「已售出」，生成一笔订单。
2. **确认收货**：买家在线下完成交易后，到 **「我的订单」** 点击「确认收货」，货款才会转入卖家钱包。
3. **取消退款**：在确认收货前，买家可以取消订单，货款将原路退回买家钱包，商品恢复「在售」。

**买家操作**：首页 → 商品详情 → 「立即购买」；之后在 **「我的」→「我的订单」** 中确认收货或取消。

**订单状态**：

| 状态 | 含义 |
| --- | --- |
| 待确认收货 | 买家已付款，货款暂存，等待买家确认收货 |
| 已完成 | 买家已确认收货，货款已转入卖家钱包 |
| 已取消 | 买家已取消，货款已退回买家钱包 |

**安全提示**：平台只负责虚拟币的托管与划转，请务必线下当面验货后再「确认收货」；一旦确认收货，货款将不可追回。
