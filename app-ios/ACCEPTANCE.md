# 校园闲置 iOS 四级验收标准

本文件对应产品确定的四个优先级。每一级必须完成该级所有条目并取得功能、权限、异常、适配与自动检查证据后，才能标记通过。四级全部通过后统一提交。

## 全局完成定义

- 支持工程当前最低版本 iOS 17，Swift 6 构建不新增警告。
- iPhone 竖屏/横屏和 iPad 不出现内容截断、横向溢出或不可点击控件。
- 浅色、深色、动态字体、VoiceOver、安全区和“减少动态效果”可用。
- 请求期间防止重复提交；加载、空数据、离线、超时和服务端错误均有明确状态与重试入口。
- 未登录、非校园认证、非资源所有者不能通过客户端绕过服务端权限。
- 每一级必须更新本文件证据栏，不能只以“构建成功”代替功能验收。

## 第一优先级：补齐 Web 与 iOS 的功能差距

### 1. 快递代取

- [x] 主导航提供“代取”入口，列表支持需求/服务、关键词、地点和状态筛选及下拉刷新。
- [x] 详情展示方向、货物类型、取送地点、时间、价格、发布人、备注和状态。
- [x] 校园用户可发布和编辑自己的代取；表单使用服务端地点目录并执行与 Web 一致的校验。
- [x] “我的代取”可查看本人全部状态记录，并执行服务端允许的编辑、完成、关闭和删除操作。
- [x] 非发布者可从详情发起站内会话；消息正确展示代取卡片。
- [x] 未登录、非校园账号、空列表、网络失败和重复提交状态完整。

### 2. 商品管理

- [x] 本人商品详情和“我的发布”提供编辑入口，非本人不显示管理操作。
- [x] 编辑表单回填标题、价格、币种、图片、分类、成色、描述、发布校区和状态。
- [x] 可上架、下架、标记售出并在详情/列表同步最新状态。
- [x] 支持仅本人删除；客户端二次确认，服务端覆盖本人成功、他人 403、缺失 404。
- [x] 可保留、添加、移除和排序图片，规则与发布一致。
- [x] 新建/编辑内容在失败或意外离开后保留草稿，可恢复、重试或主动清除。

### 3. 校园与校区

- [x] Codable 模型和会话层加载 `GET /api/campuses` 的学校、校区及默认范围。
- [x] 首页、登录注册、个人中心、卖家主页、发布不硬编码学校/校区或 `ruc_suzhou`；代取将在对应子项复用动态范围。
- [x] 登录用户使用账号的 `schoolName`/`campusName`；游客使用目录默认范围。
- [x] 注册按邮箱域名匹配学校，多校区时选择合法校区。
- [x] 个人资料可在所属学校内切换校区，明确学校不可修改；保存后刷新会话与范围数据。
- [x] 目录失败有降级文案且不阻塞基本浏览和登录。

### 4. 钱包、订单和成就

- [x] 个人中心展示原石、创世结晶余额，并可查看最近流水。
- [x] 订单列表区分买家/卖家，展示金额、币种、对方、创建时间和担保状态。
- [x] 买家可确认收货或取消允许取消的订单；危险操作需确认，结果及时刷新。
- [x] 商品详情对支持的在线币种提供下单入口，余额不足与非法状态提示明确。
- [x] 个人中心展示成就徽章、名称、描述和进度/数值，空状态合理。

### 第一优先级验收门槛

- [x] 上述四项全部通过真实 API 或可重复的测试数据验收。
- [x] 后端相关权限与状态机测试通过。
- [x] iOS Debug 模拟器构建通过，关键页面完成 iPhone 与 iPad 截图验收。

## 第二优先级：完善移动端体验

### 首页与搜索

- [x] 首页分页或无限滚动，首屏不一次加载全部商品；刷新能重置游标且不重复数据。
- [x] 搜索输入有防抖和请求取消，旧响应不能覆盖新查询。
- [x] 保存有上限、可清除的本地搜索历史；筛选面板覆盖分类、成色、排序和适用范围。

### 图片体验

- [x] 商品图片查看器支持分页、双击/捏合缩放、拖动复位和当前页指示。
- [x] 保存图片前请求相册权限，成功、拒绝和受限状态均有反馈。
- [x] 上传前压缩并显示总体/单张进度；可删除、调整顺序、失败重试。

### 聊天与可靠性

- [x] 会话列表和当前会话使用可取消的稳定轮询，避免页面消失后继续请求。
- [x] Tab 与会话未读角标正确；进入会话标记已读后同步清零。
- [x] 新消息自动滚动仅在用户位于底部附近时发生，不打断向上阅读。
- [x] 消息显示发送中、成功、失败状态并支持失败重发，防止重复发送。
- [x] 键盘出现时输入框保持可见，交互式收起不造成跳动。
- [x] 离线、超时、空数据和服务端失败使用统一组件并提供重试。

### 第二优先级验收门槛

- [x] 分页去重、防抖竞态、草稿/历史和消息状态有单元测试。
- [x] 图片与聊天关键手势在模拟器完成交互验收。
- [ ] iPhone 小屏、Pro Max、iPad 和横屏无布局回归。

## 第三优先级：系统能力

### 通知

- [x] 客户端请求通知授权、注册 APNs token，并通过鉴权接口上传/注销 token。
- [x] 后端设备 token 接口校验、去重且不泄露完整 token；未配置 APNs 时不影响站内消息。
- [x] 设置页分别控制邮件消息通知和系统通知，并正确显示系统授权状态。
- [x] 新消息通知携带会话标识，前台、后台和冷启动点击均打开对应会话。
- [x] App 图标角标与服务端未读数同步，读完和退出登录后清零。

### 链接、权限和会话

- [x] 商品分享生成 Universal Link；已安装打开商品详情，未安装回落 Web 页面。
- [x] Associated Domains、站点 AASA 和路由解析配置完整并有测试。
- [x] 相机与相册用途说明存在；授权拒绝时提供前往系统设置入口。
- [x] Cookie/敏感会话数据使用合适的系统安全存储策略，不将凭据写入日志或普通偏好。
- [x] 401 会统一触发会话刷新/退出与登录引导，可恢复原目标页面，而非仅显示接口错误。

### 第三优先级验收门槛

- [x] 通知 token API、链接解析与 401 会话失效有自动测试。
- [ ] Universal Link 在模拟器/真机验证；APNs 在真机验证。
- [x] 缺少 Apple 外部凭据时，只允许把“真实远程送达”列为外部验收项；代码、接口和配置仍须完成。
